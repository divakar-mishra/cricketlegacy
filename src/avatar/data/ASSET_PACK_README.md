# Cricket Legacy Modular Avatar Starter Pack

This package contains clean, aligned modular avatar assets generated on a shared 1024×1024 transparent canvas.

## Included

- Male and female avatars.
- Narrow, medium and wide face rigs.
- Four skin tones per rig.
- Six hairstyles for each sex, with separate front and back layers.
- Five beard styles and four moustache styles for male avatars.
- Five headwear options per rig.
- Seven cricket outfits.
- Six eye colours per sex and rig.
- 300 deterministic preset recipes.
- Source SVGs, 1024px PNG masters and optimized 512px runtime PNGs.

## Layer order

1. Hair back
2. Outfit
3. Base face
4. Eyes
5. Hair front
6. Beard
7. Moustache
8. Headwear
9. Optional frame

All layers must be rendered at the same `top: 0`, `left: 0`, width and height. Do not add category-specific offsets.

## Notes

- Headwear should hide hair in the app unless you deliberately create compatible combinations.
- Female presets use no beard or moustache.
- The pack is a polished, stylized 2.5D production starter set, not a photorealistic portrait set.
- Verify visual scale inside the actual APK before expanding the catalog.

## Unresolved release evidence

1. **AAB:** Code 11 passed static validation and AAB-derived APK smoke testing. Before public rollout, install the Play-delivered build on real devices to check store signing, upgrade/save retention and SDK behavior. Do not upload superseded code 9 or 10. EAS remote app versioning sets manifest code 11 even though embedded `app.config` retains local `android.versionCode: 8`; Play reads the manifest code.
2. **Real devices/services:** A clean Play-installed test must cover both careers, save/restart, age paths, UMP accept/decline, banner/interstitial/rewarded requests and reward-on-completion only. Passing mocked tests does not prove AdMob review approval, fill, or impressions.
3. **Billing:** The sideloaded Manager Store currently says `Checkout coming soon` and shows unavailable product prices; no checkout was initiated. Confirm BillDesk/merchant review, all 14 launch products and prices in Play/RevenueCat, actual Play test purchases, cancellation, refund, restore, account switching and fail-closed behavior before claiming IAP is live. A sideloaded emulator is not a valid Play billing end-to-end test.
4. **Console and AdMob:** Confirm the target-audience/data-safety declarations match the actual age/ad behavior, the Play store title is now `Cricket: Player & Manager` (older Console screenshots still showed `Cricket Legacy`), and the release track/country setup. The owner's screenshot showed open testing restricted and an India early-access draft; verify the current Console state before rollout. AdMob's [app-readiness requirements](https://support.google.com/admob/answer/10564477?hl=en) say the app must be published, listed in a supported store, and linked in AdMob before full ad serving; a private/invite-only track should not be assumed to meet that requirement. Once publicly available, add the Play listing under AdMob App settings and monitor review/verification status. No Console submission was performed in this gate.
5. **Tooling:** Expo Doctor passed 18/21 checks but reported SDK 57 patch skew, duplicate `expo-constants`, and manual native-config synchronization because `android/` is checked in. Android release lint could not complete: Android Lint crashed while analyzing `react-native-worklets` (`Cannot find a KaModule`). This is a tool/dependency-analysis failure, not evidence of an app lint pass. The production dependency audit reported four high and twenty moderate advisories; the high packages currently resolve through Metro/Babel/Expo config tooling, not game runtime.

## Operating expectation

An early-access/open test is a validation period, not a one-year maintenance substitute. At minimum, check Play policy notices, Android vitals/Crashlytics, AdMob requests/fill/review status, billing/refund/webhook health and support/deletion requests regularly. Plan a target-SDK/Expo review before Google's next annual Play deadline; do not assume a September 2027 upgrade will be early enough.

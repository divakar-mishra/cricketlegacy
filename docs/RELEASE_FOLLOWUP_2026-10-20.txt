QA-only consent instrumentation
------------------------------
Settings has three QA session controls: regulated-US adult geography, simulated
teen ad treatment and end-session. These use the actual configureAds and Ad
privacy choices pathways. They do not persist a new age answer or modify saves.
An existing adult test session, QA JS flag, native qa build and Google's test-
device check are required before a consent reset/region override is offered.
Actual saved teen/unknown-age sessions cannot use an override to become adult.

UMP reset temporarily closes ad readiness, revokes Unity personalization and
invalidates previously loading ads. Overlapping profile/privacy operations are
blocked. A withdrawn audience cannot be resurrected by a delayed reset. A reset
error leaves ads unavailable and allows a later explicit QA retry.

Teen QA uses TFUA=true in GMA and UMP, G-rated GMA configuration and explicit
NPA request extras in the isolated native diagnostics panel. Normal teardown
removes the debug geography and reuses the normal adult configuration. The
pinned RN SDK creates a fresh native RequestConfiguration.Builder, clearing the
QA rating when that optional field is omitted. UNSPECIFIED is not a supported
RN rating enum and is not used. Cold-restart after ending QA and closing any
single-source Ad Inspector override. Prior consent is never forcibly regranted.

The diagnostics Activity remains QA-source-set-only, not exported, requires
UMP permission and a Google test device, and requires manual confirmation of
Unity dashboard test mode. It cannot verify Unity's dashboard by itself. It
logs sanitized treatment flags and computed Unity privacy-policy decisions,
not raw consent strings or account IDs. Those policy computations are not an
independent readback from Unity's ad server. No game reward is granted.

--------------------------------------

children. Google's Unity integration guide says Mixed Audience must be enabled
to process per-user child-directed/under-age-of-consent signals. The pinned

the dashboard honors it for this project. Consequently teen Unity serving is
not certified. Do not blindly change a legal age/Families declaration merely

   / Manager creation coaching begins after the actual career-mode selection.

   its handler also refuses progress until the relevant valid choice exists;
   old completed-tip state cannot bypass a currently empty required field.
   Skip guide remains an optional opt-out, NOT a form-validation bypass.
3. Player form requires a trimmed2character name, known country, explicitly
   chosen Male/Female, portrait and role before advancing. Default preview and
   default All-Rounder do not count as user selections. Changing gender requires
   choosing a portrait again. Manual portrait, Randomize and Reset are explicit
   portrait actions. Review includes gender; no points auto-spent.
4. Gender tabs and actual portrait grid have separate measured targets, with
   no100pixel crop. Creation coach reserves its own lower-screen area and leaves
   a scrollable body above; it does not overlay the avatar grid. Country modal
   temporarily suppresses the guide and then resumes it after closing.
5. Manager creation requires an explicitly chosen country and club. Country
   change clears club selection. Default difficulty/rules remain unchanged.
6. Player.sex records cricket-world identity at creation, while later portrait
   editing remains cosmetic. Names and avatars now use the selected sex.
   Added fictional female given-name pools for all12supported countries, using
   existing surnames. Same RNG call count; ability, role balance, potential,
   selection, match outcome, prices and energy rules unchanged.
7. Propagated identity into domestic rosters, national reserve pools, free agents,
   Grade A/U19 teams/opponents, U19 World Cup squads, replacement nationals,
   seasonal recruits and academy intake. Squad/profile/award NPC portraits use
   the actual Player.sex instead of always male. Standalone Manager creation
   retains its existing male world; this does not add a Manager gender selector.

# Play Store creative inputs

This smaller ZIP contains the current app icon, correctly named feature graphic, ready-to-paste listing text, the complete screenshot/video brief, selected genuine Android screenshots, and the existing live-match recording. Give the ZIP to the designer or creative tool as source material.

Start with [MARKETING_CREATIVE_BRIEF.md](MARKETING_CREATIVE_BRIEF.md), then use [PLAY_STORE_LISTING.md](PLAY_STORE_LISTING.md) for the exact title and descriptions. The `store-assets/` folder has the current icon and feature graphic. The Player and Manager PNGs are source screenshots; `player-live-70s.mp4` is actual match footage.

These source screenshots were captured before the rename and may show old branding, emulator bars or staged QA outcomes. They are references for new store compositions, not finished upload files. The video covers only live play, so the other planned video scenes require fresh recordings from the current app.
